## 怎么看原型

平板端“模拟手机扫码”选择员工→开始→结束；不再操作，设备会自动推进。员工手机端以同一演示身份登录，查看会议/资料、更正事项或共享给同事。管理员入口查看配置和异常，不自动读正文。顶部评审工具可模拟断网、保存失败、AI重试耗尽、缺群和发送结果不明。

原型始终合成数据：二维码明确不可实际扫码，没有企业微信认证、麦克风、音频文件、AI或真实群。IAM-03完整自定义角色编辑、PAD-04详细分片诊断在规范中定义，原型仅部分呈现；具体覆盖见DES-10，不伪称整个产品已完成。
