# ACL-01｜身份、功能与会议访问 v1.3

## 1. 业务角色

| 身份 | 可做什么 | 内容范围 |
| --- | --- | --- |
| 公用未登录平板 | 看设备状态、发起扫码；无历史内容 | 不可录新场，不看历史标题 |
| 本场扫码员工 | 开始/暂停/结束，开录前改有权归属 | 仅控制本场，不在平板查看历史 |
| 会议发起人 | 手机查看/回听/主动更正、授公司内只读权、撤自己授出的权 | 本人发起的会议 |
| 明确授权查看者 | 查看已生成四类资料和回听 | 对象/业务组授权范围，不能改内容或群 |
| 平台管理员 | 用户状态/组织/设备/角色/路由/异常维护 | 默认不读正文，必要业务资格显式授予 |
| 设备/服务任务 | 保存、归档、处理、自动分发 | 仅任务绑定的会议，受当前数据/出口策略约束 |

角色与对象范围逐条成对判断；不交叉拼接权限。发起人的共享仅可给予查看/回听，不包含下载、编辑、系统管理，也不能撤管理员独立来源。组成员与部门不是企业微信群名单；加入部门不开放全部资料。无普通内容审核角色前置。

## 2. 生命周期和披露

每场扫码是人员身份，设备配对独立。企业有效员工首次开户基础角色；管理员本地停用、企微失效或撤销后新登录/受控请求拒绝，不用自动开户覆盖禁用。具体组织同步时效需技术实测。

生成即可按权限查看；没有仅核对人可见的机器稿门槛。资料仍标AI来源和未知项。群摘要外发受众单独批准，群成员不自动取得记录；外网手机也必须登录与对象授权。下载/导出独立。

## 3. 安全要求

### REQ-SEC-001｜认证与对象级授权

**范围：P0；依据：建议细化。**

所有内容端点、搜索、统计、媒体播放/范围请求、下载和导出在服务端校验用户及会议范围。设备令牌只能上传和查询自身必要状态，不可充当管理员令牌。

**反馈与例外：**未认证返回登录入口但不渲染内容；无权请求不得靠猜ID读取。

**验收：TC-SEC-001, E2E-014, E2E-015。**

### REQ-SEC-002｜权限变更和凭证撤销

**范围：P0；依据：建议细化。**

停用账号、撤销对象授权和设备凭证在下一受控请求生效；缓存与短效文件凭证的残余窗口必须记录。公用设备退出维护态清理用户会话和内容缓存。

**反馈与例外：**不承诺抹去已下载资料；最大缓存窗口需在设计与验收中明确。

**验收：TC-SEC-002, E2E-016。**

### REQ-SEC-003｜秘密与传输保护

**范围：P0；依据：建议细化。**

正式传输受保护；凭证不入源码、前端包、截图、普通日志或错误回显。终端仅持有设备最小凭证，AI/企微秘密留后端。生成与轮换可审计。

**反馈与例外：**开发可用隔离本地测试配置，不让明文调试例外流入正式构建。

**验收：TC-SEC-003。**

### REQ-SEC-004｜内容展示与外部输入

**范围：P0；依据：建议细化。**

转写、标题、模板、AI输出、上传文件名和外部错误全部视为不可信输入。网页转义，限制可执行格式、外链访问和服务器任意URL请求；模型输出不能驱动系统权限。

**反馈与例外：**导出文件避免表格公式注入等风险；诊断错误不拼接用户输入执行命令。

**验收：TC-SEC-004, E2E-020。**

### REQ-SEC-005｜审计与职责分离

**范围：P0；依据：建议细化。**

维护权限和内容权限分开；高风险授权、真实分发、删除、导出与恢复可追踪到身份/设备和原因。审计写入失败时不得无痕执行高风险操作。

**反馈与例外：**普通录音不中断于远程审计服务短暂不可用，但本地事件要可后续同步。

**验收：TC-SEC-005。**

### REQ-SEC-006｜录音告知与最少采集

**范围：P0；依据：建议细化。**

平板清楚显示录音状态、用途及默认接收范围；首期不采集视频、屏幕、精确人员声纹或其他应用内容。测试录音须有授权标记，自动化不得隐蔽开启麦克风。

**反馈与例外：**告知方案由公司批准，不将按钮点击当成全部参会者的法律同意证明。

**验收：TC-SEC-006。**

### REQ-SEC-007｜备份恢复不扩大访问

**范围：P0；依据：建议细化。**

恢复环境默认禁外部AI和群发；先恢复权限、撤销记录和删除清单再开放查询。恢复不得默认管理员可读全部业务正文，也不重放已成功发送事件。

**反馈与例外：**保留最少必要的删除标记，用于防止旧备份复活已删资料。

**验收：TC-SEC-007, E2E-018。**

### REQ-SEC-008｜上线配置校验

**范围：P0；依据：建议细化。**

生产启动检查管理员初始化、环境隔离、数据保留、网络保护和外发授权；门禁缺项可只运行受限模式，不允许假定默认群或无限留存。

**反馈与例外：**门禁阻断具体危险能力，不强迫为了编译通过填写真实密钥。

**验收：TC-SEC-008, E2E-024。**

## 4. 权限变更与恢复

保存更正不重发，共享不发群。撤权/停用/删除/停用目标在新受控请求和外部动作前复核；已下载或已交付外部副本不能保证撤回。运维最高主机权限属于另外的管理边界。

故障优先自动恢复；管理员看最小错误元数据，实际读取片段需相应资格。故障复核不能重新变成所有正常会议的内容审核。
