# DES-06｜Web前端实施设计

版本：1.3-draft；技术框架尚未选定。对应PRD-04/05/06/07、DES-05及ACL-01。以下模块划分和路由为实施草案，不是已存在项目路径。

## 1. 责任边界

page负责路由与页面组合；业务组件负责局部交互；service负责类型化请求与结果转换；state负责会话、服务端数据缓存和必要编辑状态。权限展示统一读取服务端能力和范围解释，不在各页复制角色名判断。所有敏感操作后端仍重新校验。

建议业务模块：identity、meetings、transcript、distribution、organization、devices、operations。共享目录仅放基础组件、请求、日期/格式化和安全文本展示，不把所有业务状态塞入一个全局对象。

## 2. 路由与页面职责草案

| 路由 | 页面 | 主要状态/权限 |
| --- | --- | --- |
| /login | 身份入口与返回目标 | 未认证/失败/停用/恢复说明；不提前加载会议正文 |
| /meetings | 会议列表和授权搜索 | 首次加载、空、筛选空、失败、分页；过滤先于计数 |
| /meetings/:id | 详情与资料标签 | 资料独立处理状态、无权/不存在一致反馈 |
| /meetings/:id/versions/:version | 指定内容版本 | 不因存在新版自动换内容；受当前授权约束 |
| /meetings/:id/edit | 修订与版本冲突 | 基础版本、改动理由、未保存提示；编辑资格独立 |
| /distribution | 自动规则和发送结果 | 配置预演、自动快照、UNKNOWN；各动作单独检查 |
| /admin/users、/departments、/roles、/groups | 人员组织管理 | 管理资格与内容授权分开；依赖/最后管理员保护 |
| /admin/grants | 授权预览/撤销/有效权限 | 主体＋角色＋范围＋历史边界；委派资格检查 |
| /admin/devices、/jobs、/audit、/settings | 设备与运维 | 最小元数据、异常原因、受控恢复；正文另外授权 |

手机群链接复用受控会议详情路由，不创建绕过权限的公开详情。完整后台操作在支持浏览器矩阵中声明，企业微信内优先验收登录、阅读、版本和播放路径。

## 3. 会话、请求与错误

启动先取得会话摘要（身份、组织显示名、可进入功能），无会话进入登录。返回目标仅接受本站受控路径，防止开放跳转。目标只保存路径标识，不缓存未授权标题。

请求服务统一处理：401清会话并导航；403/404按不泄露策略呈现；409显示版本/内容冲突；422显示字段错误；429显示可重试时间；网络/5xx保留可操作错误。错误中关联标识可复制给维护者，不显示存储路径或密钥。

GET可按技术配置少量重试；创建、保存、授权和发布不能凭“网络断了”重复提交新动作，使用原幂等键查询或重试。正在提交禁重复按钮只是体验措施。取消页面请求不等于取消已提交的后台任务。

企业微信登录方向已确认，T-07落实具体接入；建议同源部署和安全会话cookie，若采用其他方案需同步修改DES-09。浏览器不持有AI/企业微信群凭证，不把长效敏感令牌放在持久页面状态。

## 4. 服务端数据、编辑草稿与并发

列表筛选/排序/页码可进入URL以便返回；查询缓存键至少包括当前身份、查询条件和对象版本，退出/切换账号/撤权时失效。短效媒体链接不进入长期缓存或评审截图。

草稿本地内存与已保存版本区分；提交带expected_version。409返回安全的当前版本摘要，提供对照与重载，保留用户输入，不能自动覆盖。下载/导出有各自权限；正常初始发布由系统自动推进。保存更正只更新内容版本，不阻断已冻结初始快照，也不重复发群。

后台进度建议先用有间隔的轮询并在页面隐藏时降低频率；精确间隔/是否SSE由T-03按负载与恢复能力选择。连接中断标“状态可能未更新”，不能把旧值当实时。状态只取服务端版本，不因迟到响应倒退。

## 5. 音频、逐字稿与长内容

播放请求由服务端鉴权代理或受控短效方案提供；初期建议代理，便于每次Range请求检查。播放链接到期需重新授权获取；撤权后停止新请求并清理界面，已缓存字节不能保证远程抹除。

逐字稿以段落稳定ID和来源版本定位；按实际规模分段加载/虚拟化，跳转证据前加载目标段。音频时间轴映射使用服务端提供的采集映射，页面不自行相加猜缺口。无时间戳标注不能精确定位，不能画假播放位置。

长文本搜索命中、标题、模板、用户输入、AI输出统一按文本或受限格式渲染；不直接插入任意HTML。原文中的外链不自动预取。未经批准不接分析/错误上报服务传输会议内容。

## 6. 页面状态与跨页一致性

每页至少列出加载、正常、空/未配置、失败、无权、会话过期；有编辑的页面增加脏数据、保存中、版本冲突；有异步任务的页面增加等待、重试、取消、需人工处理。状态文字取STATE-01和DES-05，不逐页翻译出不同含义。

旧v0.2原型仅历史参考；v0.3以统一合成人员和对象范围演示。正式工程不得保留第二套“前端演示权限”用于真实记录访问；测试身份通过隔离测试配置提供，正式构建不带任意切换入口。

## 7. 验证与交付

交付路由图、模块目录说明、类型化请求层、统一会话和权限入口、业务组件与代表页面、端到端自动化、受支持浏览器清单。技术库版本在T-03确认后固定。

重点验证：登录回跳与恶意return路径拒绝；切账号清缓存；无权搜索/计数不泄露；页面刷新不丢服务端事实；保存超时不重复创建；并发编辑保护；长逐字稿定位；媒体过期/撤权；手机企业微信实际访问。仅截图不能证明后端授权正确。
