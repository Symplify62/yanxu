# PRD-05｜全自动分发与异常通知 v1.3

文件名保留原编号以维持旧引用；当前普通内容审核流程已撤销。管理员按部门/业务范围配置接收群；正常完整结果自动生成消息快照并发送。员工无选群、禁发本场、逐场核对或确认发送操作。

DIST-01路由配置；DIST-02发送快照/结果；ADM-04异常处理。缺规则、目标停用、环境未启用、文件故障、UNKNOWN均明确显示并按自动恢复/管理员接管处理；不是将正常会议丢进人工待审核队列。群消息是已披露摘要，全文权限另行控制。

## 功能需求

### REQ-DIST-001｜正常会议全自动发送

**范围：P0；依据：U-11 已确认业务＋实施细化。**

首版正常会议默认自动发送，员工结束录音后无需上传/生成/核对/确认发送。取消员工侧审核后发送、仅归档与本场不发群选项。

**反馈与例外：**生产出口仍须一次性部署配置/授权；缺配置或故障不猜测目标，留存资料并由管理员处理。

**验收：TC-DIST-001, E2E-001, E2E-009。**

### REQ-DIST-002｜规则匹配与冲突

**范围：P0；依据：建议细化。**

按会议室、已提供的类型/部门和显式优先级匹配，按 STATE-01 处理冲突。展示命中规则、版本和原因。缺部门只能命中明确允许的默认规则，不猜测分类。

**反馈与例外：**同级多个不同结果阻断并通知配置负责人；无自动“取第一个”。

**验收：TC-DIST-002, E2E-007, E2E-009。**

### REQ-DIST-003｜管理员停发与当前权限收紧

**范围：P0；依据：U-11 已确认业务＋实施细化。**

管理员保留全局应急停发、连接停用和资料撤权能力；正在排队的发送执行前检查当前状态。员工没有每场不发群开关。

**反馈与例外：**故障停发不阻断本地录音/归档；已提交外部请求的内容不能保证撤回。

**验收：TC-DIST-003, E2E-007, E2E-022。**

### REQ-DIST-004｜自动发布绑定不可变快照

**范围：P0；依据：U-11 已确认业务＋实施细化。**

AI初次完成后自动冻结内容版本、已配置目标、访问范围和策略版本，形成唯一发布任务，不要求人工批准。内容保存更正不改变已冻结快照。

**反馈与例外：**目标停用/权限收紧即时检查；新宽松规则不自动重路由历史待发任务，管理员需显式处理配置异常。

**验收：TC-DIST-004, E2E-012。**

### REQ-DIST-005｜可预览消息与内容限额

**范围：P0；依据：建议细化。**

生成会议时间、会议室、简短摘要、可选事项、版本、完整记录入口及 AI 提醒。模板确定性裁剪到渠道限制内，不在字符中间破坏中文；完整信息留受控页面。

**反馈与例外：**具体字节/频率限制由适配器按当前渠道文档核实；无需长文拆成大量群消息。低质量会议必须可见标记。

**验收：TC-DIST-005。**

### REQ-DIST-006｜发送任务去重与多目标状态

**范围：P0；依据：建议细化。**

同会议＋内容版本＋目标＋发送类型建立稳定业务去重。重复完成事件只产生一个逻辑任务。多目标各自记录，不因一个失败重复发送已成功目标。

**反馈与例外：**人工补发需要新动作和理由，明确标记补发；不承诺外部渠道支持端到端恰好一次。

**验收：TC-DIST-006, E2E-004, E2E-010, E2E-011。**

### REQ-DIST-007｜超时、限流与未知结果

**范围：P0；依据：建议细化。**

按真实渠道返回判定已接收、明确失败或结果待确认。明确未成功可有界重试；请求可能已送达但响应丢失时进入未知结果，默认不自动盲重发，交人工确认。

**反馈与例外：**发送成功显示渠道已接收，不显示已读。未知结果经确认重发可能重复，应告知操作者。

**验收：TC-DIST-007, E2E-010。**

### REQ-DIST-008｜凭证和连接测试

**范围：P0；依据：建议细化。**

Webhook 由授权管理员录入受控服务端，保存后仅显示掩码与连接名。校验发送目标属于批准的渠道域与协议，防止任意地址访问。测试先显示目标和虚构内容，明确授权才真实发送。

**反馈与例外：**测试群和正式群隔离；日志/错误不得回显 URL 密钥。轮换凭证不自动把历史待发任务发送。

**验收：TC-DIST-008。**

### REQ-DIST-009｜发送与阅读权限分离

**范围：P0；依据：建议细化。**

策略管理员明确群受众可接收的摘要范围，详情单独按登录对象授权。群名单不能从机器人 URL 推断；接收群与内部访问组的映射需人工登记、定期复核。

**反馈与例外：**正文访问被撤销时未来请求拒绝，但无法撤销群里已经看到的摘要或下载副本。

**验收：TC-DIST-009, E2E-014。**

### REQ-DIST-010｜主动更正不自动重复通知

**范围：P0；依据：U-11 已确认业务＋实施细化。**

初次AI产物按规则自动发送一次。员工可选更正形成新版本，旧发送快照保持；保存本身不重发。显式更正发布若后续提供，必须独立动作、权限与新发布号。

**反馈与例外：**首版原型只演示保存更正和旧发送版本提示，不增加正常确认发送按钮。

**验收：TC-DIST-010, E2E-013。**

### REQ-DIST-011｜可解释的配置预演

**范围：P0；依据：建议细化。**

发布规则前选择合成样例或授权已有会议预演，只计算结果，不发消息。显示预计模式、目标、内容范围、配置与权限冲突。发布新规则默认仅作用新会议。

**反馈与例外：**重评历史待发会议须显式范围和数量确认，重新校验权限和冻结快照。

**验收：TC-DIST-011, E2E-009, E2E-022。**

### REQ-DIST-012｜异常自动恢复与管理员告警

**范围：P0；依据：U-11 已确认业务＋实施细化。**

上传/转写/总结/发送先按故障类型自动恢复；重试达到上限或发送结果不明时通知管理员。发起人手机显示状态但不承担维护操作。

**反馈与例外：**现场采集/保存故障在平板立即提示；渠道故障不能只依赖同一失效渠道告警；UNKNOWN不盲重发。

**验收：TC-DIST-012, E2E-011, E2E-031。**
