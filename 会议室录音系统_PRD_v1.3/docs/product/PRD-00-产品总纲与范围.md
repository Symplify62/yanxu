# PRD-00｜产品总纲与范围 v1.3

业务来源U-11已确认；技术方案与实现状态分别登记。公司内部安卓平板录音，员工手机企业微信扫码开始一场会议，结束保存后即可离开；系统自动上传、转写、总结、提取事项并发群。本人/明确授权人员在公司内外手机查阅原音频、逐字稿、纪要与事项。

## 首期边界

首期一间会议室、通常五人中文，不硬编码room或群。每场有明确发起人和默认部门，开录前只允许有权归属调整。有效企业员工首次登录自动建档；设备凭证、员工会话和服务任务分开。扫码是否真实可用必须联调，当前原型只演示。

普通主流程无人工核对、审核或确认发送。无本场禁发开关；群目标由管理员配置。技术异常、缺规则、文件缺口或已停用目标不伪装成功，不猜群；自动恢复失败由管理员处理，员工手机看状态不承担维护任务。

## 资料、权限与保留

四类资料按完成进度即时可见，仍标明AI来源和不确定字段。本人可共享只读权限、主动更正；更正保存不重复发群。群摘要受众与全文查看资格分别管理。下载/导出独立授权，维护管理员无默认正文权限。

录音不设业务时长上限；分段只作为技术实现，最终仍一场会议。资源不足必须告警和保护已有内容。公司档案长期保留，设备缓存仅按受控条件清理；实际容量、备份和费用需要测算。

## 实施与验收

沿用96条需求并按版本修订，产品验收规格见TEST-01；页面与组件规则见DES-10及UI用例。前端规格/原型、正式代码、真实集成、真机与生产验收分别记录。外部AI方向允许，具体供应商/资料条款/预算尚待落实，不授权任意外发。

保持排除：实名声纹识别、实时字幕/直播、预约平台、自动考核催办、商业多租户、Wave前置依赖。技术细节由开发调查，不把框架和表名交给用户逐个选择。
