# PRD-04｜手机资料查阅与可选更正 v1.3

WEB-01后台会议列表；WEB-02详情；WEB-03可选更正；WEB-04异常状态。MOB-01手机本人/授权列表；MOB-02四类资料；MOB-03主动更正；MOB-04只读共享；AUTH-01企业微信身份入口；DENY-01无权反馈。

公司外也应有受控登录/查阅路径。资料完成哪项就能看哪项，无人工审核前置。原型没有真实声音时必须说明，不播放虚构采集音频。保存更正不自动发群；列表、计数、音频、导出都校验对象权限。

## 功能需求

### REQ-LIB-001｜本人和授权会议的手机查询

**范围：P0；依据：U-11 已确认业务＋实施细化。**

企业微信员工可在公司内外通过受控手机页查看本人发起及明确授权的会议，管理员维护身份不自动读正文。逐项产物生成后按权限立即可见，不等待整场人工审核。

**反馈与例外：**列表/搜索/计数/媒体/导出使用同一对象权限；部门归属不等于部门全员可见。

**验收：TC-LIB-001, E2E-015, E2E-029。**

### REQ-LIB-002｜四类资料统一详情

**范围：P0；依据：已确认完整资料＋建议界面。**

一场会议聚合原始音频、逐字稿、纪要和事项，分别显示版本、完整性、处理状态、来源。尚未生成时显示处理中/失败/未配置，而非伪造空白成功。

**反馈与例外：**能先看已授权且已完成部分；例如纪要失败不阻止有权用户回听原件。

**验收：TC-LIB-002, E2E-006。**

### REQ-LIB-003｜播放、定位与下载

**范围：P0；依据：建议细化。**

逐字稿/事项证据可跳到有效音频位置；暂停与异常缺口映射一致。播放与下载每次校验权限，采用受控响应或短效访问方式，撤权在下一受控请求生效。

**反馈与例外：**已下载副本和已缓存播放内容不能承诺远程删除；访问令牌有效期需记录。

**验收：TC-LIB-003, E2E-015。**

### REQ-LIB-004｜可选手机更正与版本保留

**范围：P0；依据：U-11 已确认业务＋实施细化。**

发起人可在手机查看原文/回听并主动更正纪要或事项，保存新版本并保留机器原版。人工修改是可选能力，不阻断初始自动发布。

**反馈与例外：**保存更正不自动重发群消息；旧消息仍指向原发送快照，详情提示存在新版本。

**验收：TC-LIB-004, E2E-013, E2E-032。**

### REQ-LIB-005｜并发编辑与过时结果

**范围：P0；依据：建议细化。**

同一内容并发编辑使用版本检查。版本不一致拒绝无提示覆盖，展示冲突并让用户合并或重载。转写变化标记关联纪要/事项可能过时。

**反馈与例外：**旧 AI 结果晚到不覆盖人工稿；选择保留旧内容必须显式确认。

**验收：TC-LIB-005, E2E-012。**

### REQ-LIB-006｜事项待确认与可选整理

**范围：P0；依据：U-11 已确认业务＋实施细化。**

事项保留未知负责人/日期及证据，发起人可选补充/更正，状态用于内容整理。未知值、未主动确认不是自动发布门槛。

**反馈与例外：**不自动创建企业微信待办、催办或绩效任务。

**验收：TC-LIB-006。**

### REQ-LIB-007｜受控导出

**范围：P0；依据：建议细化。**

首期支持单场授权导出：原音频按权限获取；逐字稿、纪要、事项以可读文件导出，首期格式建议 TXT/Markdown 与事项 JSON。记录会议及版本、完整性、生成时间和导出者。

**反馈与例外：**批量导出及精排 PDF/Word 为 P1；导出需消除可执行注入，不包含后台密钥。管理员可禁导出。

**验收：TC-LIB-007。**

### REQ-LIB-008｜删除、撤权与保留锁

**范围：P0；依据：建议细化。**

业务授权人员申请删除，按保留策略与审核执行；记录进入不可常规访问状态，并停止未完成处理/分发。保留锁阻止物理清理，理由和到期复核可查。

**反馈与例外：**删除不是擦除审计证据；已发群摘要不能保证撤回。详细生命周期依 NFR-01。

**验收：TC-LIB-008, E2E-019。**

### REQ-LIB-009｜企业微信登录与外网手机查看

**范围：P0；依据：U-11 已确认业务＋实施细化。**

员工在公司网络之外也能通过受控入口登录查看自己的/授权会议。采用企业微信身份，登录成功回到原目标；网络与身份真实接入要分别验收。

**反馈与例外：**群摘要接收不自动授予全文；登录前/无权时不泄露正文或标题。

**验收：TC-LIB-009, E2E-001, E2E-014, E2E-032。**

### REQ-LIB-010｜自动处理和发送状态

**范围：P0；依据：U-11 已确认业务＋实施细化。**

详情显示采集/归档/各产物/分发状态、来源版本、修改与发送记录。正常路径没有待审核或确认发送状态。

**反馈与例外：**发送显示渠道已接收而非已读；异常通知管理员，员工只看实际状态。

**验收：TC-LIB-010。**
