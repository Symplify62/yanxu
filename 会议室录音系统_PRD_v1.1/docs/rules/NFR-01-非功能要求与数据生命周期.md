# NFR-01｜非功能要求与数据生命周期

## 1. 目标与指标性质

首期针对一间五人中文会议室，不做空泛的百万并发承诺。以下行为是建议的首期要求；尚无实机和成本数据的数值列为待批准。测试条件、测量结果、目标与验证结论分别保存。

| 指标 | 测量方法 | 初始验收安排 |
| --- | --- | --- |
| 正常开始响应 | 点击至实际首帧/采样写入及界面状态分别计时 | 提议≤2秒作为体验目标，待真机确认，不是实测 |
| 正常结束本地保存 | 结束至封存收据，按最长会议实测 | 提议≤5秒；安全持久化优先，超时明确显示处理中 |
| 连续录制 | 比较实际音频、单调时钟、首中尾标记 | 2小时为开发长测样例；最终最大时长由D-01批准 |
| 异常损失窗口 | 不同写入时点故障注入测最后可恢复位置 | 待选分段/容器后测量；不得承诺零损失 |
| 上传完成时间 | 文件大小、有效带宽、排队、校验分别记录 | 不对所有网络写固定秒数；批准场景做基线 |
| 处理时延 | 排队/转写/总结分别测总时长与实时系数 | 同样本比较云/本地，D-13批准目标 |
| 查询体验 | 已授权1000条合成记录上测列表/搜索 | 提议常用列表p95≤2秒，环境/并发必须附报告 |
| 恢复目标 | 从故障判定到可读及队列可恢复 | RTO、RPO由D-10批准，无证据不预填通过 |
| 容量 | 码率×时长、片段/衍生件、保留日数、备份副本 | 按真实编码测量，报警线D-12批准 |

## 2. 跨模块非功能需求

### REQ-NFR-001｜状态持久与崩溃恢复

**范围：P0；依据：建议细化。**

本地会话、上传收据、处理任务和分发任务能够在进程/服务重启后恢复。状态迁移防止并发乱序和重复回调导致逆转。不同组件故障不会让UI虚构成功。

**反馈与例外：**原子边界由技术设计说明，不能用内存队列作为唯一任务记录。

**验收：TC-NFR-001。** 既有数据可解释恢复，不多建会、不重复外发、无假成功。

### REQ-NFR-002｜长录音与容量边界

**范围：P0；依据：建议细化。**

正式支持时长和积压容量必须被明确批准并测试。保证批准负载内资源受控；达到容量阈值采取阻止不安全新录/清晰提示，不删除唯一未传原件。

**反馈与例外：**长录音拆段不得制造明显缺音或重复语句；不为测试通过缩短需求上限。

**验收：TC-NFR-002。** 批准负载内稳定；边界可见且原件安全，首中尾齐全。

### REQ-NFR-003｜备份与可恢复性

**范围：P0；依据：建议细化。**

生产备份包含原件、关联库、访问策略、版本、删除/去重及恢复密钥。恢复在禁外发隔离环境验证，对比抽样音频、权限和业务状态。

**反馈与例外：**备份成功日志不是恢复通过；RTO/RPO没有批准时不能宣称已达标。

**验收：TC-NFR-003。** 能够按批准目标恢复，权限与已删/已发状态保持。

### REQ-NFR-004｜数据生命周期与安全清理

**范围：P0；依据：建议细化。**

所有资料类型有明确保留和清理归属。删除动作执行前阻止后续AI/发送，并记录墓碑/删除清单；后台运行任务的迟到结果也不能重新发布。备份内删除以批准保留窗口和恢复过滤处理。

**反馈与例外：**第三方AI副本、群摘要和用户下载不在本系统可保证删除范围，UI需说明。

**验收：TC-NFR-004。** 会议不复活、无迟到发布，外部残留边界如实呈现。

### REQ-NFR-005｜可观测性与故障可操作

**范围：P0；依据：建议细化。**

为会话到处理/发送建立关联标识；后台可看队列年龄、失败原因、设备在线、容量、服务费用、备份时间。每类失败有负责人及恢复说明，日志最小化。

**反馈与例外：**外部渠道故障仍在本系统显示；健康检查不播放或转存无关音频。

**验收：TC-NFR-005。** 告警/列表准确，不需要读全文即可定位技术故障。

### REQ-NFR-006｜中文与可用性

**范围：P0；依据：建议细化。**

平板主要操作大且明确、状态不只靠颜色；中文错误说明可行动，后台与企微移动网页均可读。录音、暂停、结束不因横竖屏或字体设置错位导致误操作。

**反馈与例外：**无实时字幕要求；首次配置后的普通流程不用技术字段。

**验收：TC-NFR-006。** 能够区分已保存与已发送，不需人工上传；可记录误触/困惑改进。

### REQ-NFR-007｜可升级与可回退

**范围：P0；依据：建议细化。**

版本固定并记录构建、数据库迁移、配置兼容和回退步骤。升级不在采集中发生；破坏性迁移前备份。恢复旧版本若不能读新数据，明确停止而不是盲回滚。

**反馈与例外：**开源依赖更新须重新核验许可、安全和兼容，不追随未测试latest。

**验收：TC-NFR-007。** 可恢复的步骤明确，无数据误删或重复发送。

### REQ-NFR-008｜测试证据分级与发布约束

**范围：P0；依据：建议细化。**

每次验证注明环境、版本、样本、输入方式、真实外部调用与结论。测试数据/结果不被冒充生产事实；所有P0验收含必要的实机层级，缺证据不可标通过。

**反馈与例外：**本PRD包只通过文档结构检查，不包含录音软件的任何已运行测试。

**验收：TC-NFR-008。** 状态分别为相应层级待验/被阻断，不虚构真机通过。


## 3. 生命周期矩阵

| 数据 | 存放与保留 | 清理和恢复规则 |
| --- | --- | --- |
| 平板原始片段/清单 | 私有存储，受控凭证；期限D-09 | 未归档/冲突/保留锁不可自动删 |
| 服务端原件 | 私有对象/文件存储＋关联库 | 按批准期限；派生件不能代替原件校验 |
| 逐字稿/纪要/事项 | 版本化且按会议授权 | 删除联动搜索索引、导出与缓存 |
| 下载/播放缓存 | 最小范围与短期时效 | 已下载给人的副本不能远程保证删除 |
| 任务与审计 | 保留必要标识、状态和原因 | 不存秘密；必要删除标记覆盖备份可恢复窗口 |
| 备份 | 独立授权位置，期限明确 | 恢复先应用撤权/删除/去重，再开放访问 |
| 外部AI数据 | 依批准供应商和数据条件 | 记录去向及删除请求能力，不假定全由本系统控制 |
| 企微消息 | 外部已披露摘要和入口 | 不承诺可自动撤回或清除成员截图 |

## 4. 容量和成本计算口径

音频存储量 = 每月录音秒数 × 实测平均码率 ÷ 8，再乘保留月数，并另计片段开销、派生件和备份。此式是估算口径，不能当作已测容量；无月时长输入不输出虚假月费用。

云端费用 = 实际转写计费量 × 对应单价 ＋ 总结输入/输出计费 ＋ 存储/流量 ＋ 因失败造成的实际重复用量。本地成本另计硬件折旧、能源、运维、备份与许可。实际价格/硬件规格选定前保持待定。

## 5. 保留与删除执行次序

删除申请 → 核对权限/保留锁 → 阻止新处理、下载与发送 → 设置受控删除标记 → 取消或隔离未完成任务 → 清理当前存储/索引/导出 → 按批准窗口淘汰备份并在恢复时过滤 → 审计记录清理结果和不可控制的外部副本边界。

原件丢失、匿名外泄、未授权外发、权限绕过、重复大量群发为停止试点的严重事件。先停止相应外部处理与分发、保护现场和原件，再修复与重新验收，不能通过隐藏报错继续运行。
