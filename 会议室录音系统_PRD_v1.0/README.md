# 会议室录音与会议记录系统｜PRD文档包

**v1.0-draft｜2026-09-20｜评审稿**

面向一间通常五人的中文会议室，使用安卓平板录音；结束后自动归档、形成原始录音/逐字稿/纪要/行动事项，并按可配置规则发企业微信摘要及受控入口。公司内部使用，Codex开发，模拟器先行、真机后验。

这是完整需求与验收资料，不是已开发软件。用户已确认目标与本次建议细则在BASE-01中分开记录。技术路线、真实群、数据访问/保留、AI服务和费用仍有待决项，不能把评审稿视为生产授权。

## 开发入口

向Codex发送：“请读取START_CODEX.md，按本套PRD从WP-00开始，实际实现并验证，持续更新状态。先用隔离数据和模拟器，未经批准不使用真实会议、不调用付费外部AI、不发真实群、不删除正式资料。”

## 先不做什么

不要求购买Wave，不依赖其MQTT/API；不做隐蔽远程录音、实名声纹、会议预约或商业多租户；不强制某开源项目或后台框架；不预先宣布本地/云端哪条更优。历史Wave资料仅保留参考。

## 校验

在本包根目录执行 `python tools/validate_prd.py`。它只核验文档、编号、用例关联和本地链接，不运行任何软件或录音测试。结果见DOCUMENT_QA.json；文件完整性见MANIFEST.sha256。
