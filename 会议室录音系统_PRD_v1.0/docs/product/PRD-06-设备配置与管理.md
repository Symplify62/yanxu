# PRD-06｜设备、配置与管理

## 1. 首期管理范围

一间会议室也需要独立设备身份、用户、接收目标和版本配置，但无需建设大型设备管理平台或多租户计费。后台分为会议室/设备、用户与访问组、AI 服务配置、分发配置、异常任务、审计与保留策略。业务配置变更必须留痕，配置秘密只由受控服务使用。

## 2. 页面清单

| 页面 | 主要内容 | 关键限制 |
| --- | --- | --- |
| ADM-01 设备 | 会议室、设备、最近上报、授权、存储、待传数量 | 未上报显示未知，不假定在线/正常 |
| ADM-02 配置 | AI 数据边界、规则、模板、时长/空间阈值 | 草稿、校验、发布、回退分开 |
| ADM-03 用户权限 | 账号、业务组、角色和对象授权 | 系统管理不天然授予内容查看 |
| ADM-04 异常任务 | 上传、处理、发送的独立失败及恢复 | 不提供一键忽略所有错误后成功 |
| ADM-05 审计与生命周期 | 操作事件、保留锁、删除与恢复记录 | 日志不包含密钥、完整录音和全文 |

## 3. 功能需求

### REQ-ADM-001｜会议室与设备配对

**范围：P0；依据：建议细化。**

管理员创建会议室并用一次性配对方式绑定平板。设备凭证有独立标识、作用域和撤销方式；一次性配对信息不可永久复用。会议室改名不重写历史采集快照。

**反馈与例外：**设备更换可绑定同会议室；旧设备的未上传数据按受控恢复处理。

**验收：TC-ADM-001。** 配对一次有效，旧会议归属可追溯，身份不可混用。

### REQ-ADM-002｜账号、角色和对象范围

**范围：P0；依据：建议细化。**

提供最小可用登录与人工配置账号/访问组，或经审批复用现有身份系统。录音设备身份与用户身份分开。停用用户后撤销会话并停止新访问；企业微信登录是可后置适配，不等同群推送。

**反馈与例外：**无共享默认管理员密码；首个管理员由部署者一次性设置。管理权限授予须审计。

**验收：TC-ADM-002。** 两类权限隔离，停用后新请求拒绝，无硬编码凭证。

### REQ-ADM-003｜设备健康与离线状态

**范围：P0；依据：建议细化。**

设备上报最近在线、App/系统版本、采集状态、存储和待传数量。显示上报时间，超时转离线或未知。告警只反映可观测事实，不把未上报解释为正常。

**反馈与例外：**不采集无关员工应用内容和身份数据；指标不要求持续录音或监听。

**验收：TC-ADM-003。** 后台显示准确的观测时间/未知状态及可操作提示。

### REQ-ADM-004｜配置版本与生效边界

**范围：P0；依据：建议细化。**

配置由草稿、校验、发布、回退组成。设备开始时保存配置快照；录音参数变更不破坏正在录音。安全禁用、访问收紧和全局停发在服务端下一相关动作前检查。

**反馈与例外：**回退是发布一个新版本而非抹掉历史；放宽数据外发不自动应用旧录音。

**验收：TC-ADM-004。** 采集中配置稳定；安全收紧生效；版本变化有记录。

### REQ-ADM-005｜AI 连接、费用和数据边界

**范围：P0；依据：建议细化。**

分别配置音频转写、文字总结的允许服务、部署位置、数据地域说明、预算与限额。新增外部服务需要批准。连接测试只用合成材料，默认不测试真实会议。

**反馈与例外：**服务配置未批准不阻断本地采音和归档，只保持待处理；密钥仅存受控后端。

**验收：TC-ADM-005。** 不无授权外发，费用受控，失败对管理员清晰。

### REQ-ADM-006｜异常恢复工作台

**范围：P0；依据：建议细化。**

提供按失败类型的重试、重新授权、冲突调查、补传恢复与停止操作；展示影响会议和预期结果。恢复不重新计入已成功的上传/分发，不允许跳过权限校验。

**反馈与例外：**批量危险动作须范围预览和确认；恢复理由进入审计。

**验收：TC-ADM-006。** 只对许可失败范围生效，成功目标不重复，无越权。

### REQ-ADM-007｜审计与隐私最小化

**范围：P0；依据：建议细化。**

记录绑定、权限、查看/下载、修订、审核、规则发布、发送、恢复、删除等事件及操作者或设备身份、时间和对象。普通日志记录相关标识和错误码，不记录凭证/全文。

**反馈与例外：**匿名录音只记设备，不编造人员；读取音频的事件不能宣称用户已听完整会议。

**验收：TC-ADM-007。** 能复核变更与访问，日志无秘密和无必要会议正文。

### REQ-ADM-008｜保留策略与容量治理

**范围：P0；依据：建议细化。**

管理员配置经批准的设备、服务器、派生件和备份保留策略；显示容量预测、保留锁和待清理数量。策略缩短先预演，不立即批量永久删除。

**反馈与例外：**保留期未批准时禁自动删除并阻断正式上线；试用测试数据单独管理。

**验收：TC-ADM-008。** 受保护数据不删，影响范围清晰，正式删除须授权。

### REQ-ADM-009｜备份与恢复演练

**范围：P0；依据：建议细化。**

备份原件、业务库、权限、必要配置和独立可恢复的密钥材料，敏感部分分开控制。恢复演练校验音频、版本、权限、待发去重、删除清单和审计；恢复环境默认禁发。

**反馈与例外：**恢复目标时间与允许数据损失由指标批准，不能只以备份任务显示成功验收。

**验收：TC-ADM-009。** 原件/权限可用，已删不复活，已发不重发，日志可核对。

### REQ-ADM-010｜环境与发布门禁

**范围：P0；依据：建议细化。**

区分开发、测试、试点、正式环境的账号、数据、存储和外部凭证；构建和迁移可追溯。生产启用必须满足 ACC-01 与 BASE-01 门禁，不因为模拟器通过就自动开群。

**反馈与例外：**首期允许轻量部署，不要求微服务；提供回退和故障处置说明。

**验收：TC-ADM-010。** 系统明确阻止危险外发/删除，未完成门禁可见。
