# TEST-01｜验收用例库

版本：1.0-draft；全部用例初始未执行。以下是可执行测试规格，不是已运行报告。L1至L5定义见ACC-01；带多个层级的用例要分别记录结果，不得只跑最低层就统称通过。

## 1. 统一前置条件

除用例另有说明，使用隔离环境、已批准测试身份、合成/授权样本和明确版本。真实外部调用须单独授权；没有真实服务时可用受控假服务验证逻辑，但证据标记mock。执行前保存配置和文件摘要，执行后检查状态、原件及外发计数。每个用例实际结果、缺陷和证据路径写入新的run记录，不改本规格中的预期。
