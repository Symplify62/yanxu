# Android 0.3.1：直接录音与按需登录

2026-09-22，用户明确要求App打开即可录音，保留独立登录入口；只有选人和声音功能需要先登录。本轮在0.3.0账号及云端声音基础上调整Android交互，沿用已有匿名上传接口，不增加后端匿名人员或声音权限。

## 用户路径

| 入口/状态 | 预期结果 |
| --- | --- |
| 未登录打开App | 进入快速录音，显示“开始录音”；头部有“登录” |
| 未登录开始录音 | 需要时请求麦克风权限，普通录音本地保存后自动上传；无需登录 |
| 未登录选择参会者 | 打开全屏登录页；登录并同步成功后进入人员选择 |
| 未登录声音档案 | 打开同一登录页；成功后进入声音档案人员列表 |
| 登录失败/返回/取消 | 不启动麦克风，不创建录音；失败保留账号输入并允许重试，返回恢复原页面 |
| 登录成功 | 继续发起登录前的功能，登录本身不开始录音或声音采集 |
| 有效组织者账号 | 可选人、管理允许范围内的声音，新录音保持账号归属 |
| 普通成员无record权限 | 可普通录音、维护本人声音；选择参会者提示无权限 |
| 已选人后登录过期 | 隐藏缓存人员内容；开始时要求重新登录或显式清空本场名单 |
| 清空本场名单 | 仅取消本场选择，保留声音与历史录音；再次点击开始才录音 |
| 录音/声音采集中 | 人员入口保持锁定，录音名单不在处理中变更 |
| 设置→导入音频 | 不要求登录；文件选择器打开前冻结录音方式和上传服务 |

全屏登录页沿用A方案颜色、间距和简洁文案。账号、密码有持续可读标签；提交中阻止重复点击；失败在页面内显示。取消后才返回的登录响应不保存会话，也不重新打开选人或声音入口。

## 录音归属与上传边界

模式在录音开始或打开导入选择器时冻结，后续上传不根据当前账号重新猜测。

- **anonymous**：元数据有`recordingMode=anonymous`和固定`uploadServer`，没有`cloudIdentity`和`participantsSnapshot`。后续登录或换账号不接管该文件；更改App服务地址不改变已保存录音的上传目的地。
- **managed**：有效且具有record权限的账号保留此模式，即使本场没有选人。元数据冻结原账号、服务、名单和幂等标识。退出、会话过期、权限变化或换服务不能改用匿名接口上传。
- 已有名单但没有有效record身份时，创建被拒绝，用户可重新登录或明确取消选择。不会以恢复普通录音为由静默删除名单。
- 录音服务在创建目录、分配麦克风之前重新检查模式、服务、managed原账号及名单对应关系。匿名模式混入账号/名单、模式不明、managed身份损坏、非法服务地址均拒绝开始。
- 普通录音上传仍走原公开记录链路；受控录音仍走managed接口，服务端保留真实鉴权。公共回听/下载与公共编号、授权实名逐字稿规则不变。
- 旧版本匿名文件继续兼容；已有0.3.0具名文件仍按原身份上传，不要求改写或批量迁移历史录音。

代码入口：`MainActivity`负责入口、登录续接和开始时快照；`LoginPage`负责全屏登录表单；`CloudAccountUi`负责会话、目录同步和声音操作；`RecordingIdentity`定义模式/归属；`RecordingService`在启动时复核；`UploadJob`按已保存归属选择协议。

## 发布与回退

本版未改变数据库结构或服务器身份规则。发布应使用release对应源码构建，核对包名、versionCode及与旧包一致的签名，先上传并验证不可变APK，最后替换自动更新清单。已安装更高版本不能通过自动更新降级；需要回退行为时以更高versionCode发布修正版。不得通过清空App数据恢复旧行为。

发布完成后在本记录补充实际源码提交、APK路径与SHA256、线上更新清单结果、升级前后录音和设置保留证据。完整自动更新约定见[Android自动更新](android-updates.md)。

设备证据在`.local-data/evidence/guest-recording/`：`guest-home.png`、`guest-recording.png`、`guest-paused.png`、`guest-uploaded.png`，`login-for-people.png`、`login-error.png`、`login-resumed-picker.png`、`login-resumed-own-voice.png`、大字体/横屏图，以及`anonymous-recording-verification.json`和原生检查日志。实际发现全屏登录返回按钮与API36状态栏重叠，修复Insets后原点击返回路径通过；字体缩放会由Android重建Activity并清除登录输入，重新打开大字体界面验证。
