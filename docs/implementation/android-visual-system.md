# App 视觉系统整理

## 范围与验收约定（2026-09-23）

用户已确认按本轮视觉审查落实。分支 `feat/mobile-visual-system`，基线 `217e9ae`；修改前工作区干净。沿用 A 的暖白、绿色，实施移动端布局和原生共享控件，不改变录音身份、目录权限、上传、转写或云端声音同意规则。

- 设置、个人设置、人员选择、声音档案使用可返回的完整页面；只有确认/少量输入使用弹窗。个人设置接通现有 POST /api/auth/password：旧密码校验、6 位起的新密码、重复确认，成功清除本机会话并重新登录；不修改后端策略。
- 导入音频移到录音和本地记录入口；服务地址放在高级设置。保存动作只跟随具体字段。
- 录音首页保留免登录录音、顶部头像登录入口和登录后的头像选人；全选只作用当前可见/筛选人员，每个人保留声音入口；录音期间名单锁定。
- 主动作、轻操作、导航项与危险操作区分；消除系统按钮的灰色底和默认阴影。账号、登录、声音、设置共享文字、间距、输入框和页面导航。
- 公共/本地记录压缩空白，结果详情优先正文，处理完成收为简短状态；失败、无语音、中断等必要提示保留。
- 声音采集保持显式开始、试听、本人姓名确认、本机保存同意及另行云端同意；本轮不改识别算法。
