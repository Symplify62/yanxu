# 无语音结果修复（2026-09-21）

## 行为与验证约定

两条公网短录音的 ASR 结果为 `complete_no_speech`，却显示转写失败。修复范围包括本地/远程 worker、结果校验、任务终态、列表筛选与公共详情。用户已确认区分无语音和真正异常，保留原音，跳过 AI 分析。

- 新终态 `no-speech`：已正常处理、未检测到语音；归入“已完成”筛选，不占待处理容量、不安排分析、不自动重试。
- 仅接受 ASR 明确的 `complete_no_speech` 且没有文本/段落；格式错误、覆盖异常和时间缺失仍属于失败，不能由“不可重试”推断无语音。
- 远程结果通过已有机器鉴权、租约 owner 与 complete 接口提交；空转写没有明确标识仍拒绝。旧 worker 的 fail 标志不自动迁移成正常结果。
- 可见 UI：中性标签“未检测到语音”；详情说明“录音已保留，已跳过 AI 分析”，提供原音播放/下载；中断提示独立保留。不显示分析等待动画或伪造摘要。
- 两条旧失败记录仅按确定 ID 重试，用已有原音重新得出结果，不按旧通用错误字符串批量改库。

验证：先新增后端失败测试，覆盖明确无语音、非法空结果、旧租约、普通不可重试异常、分析跳过、容量与筛选、原音完整性；运行后端回归及前端构建/单测；浏览器验证无语音列表与详情、正常有语音记录和异常记录；公网发布后检查两条记录、原音哈希及模拟器截图。发布前备份、采用新版本目录，保留回退点。

GitNexus 已刷新索引并定位 validate_transcript → complete。transcribe 默认参数调用和 Store.finish 动态接收者无完整边，已用 worker/process_remote/complete 的源码与跨接口测试补充，未把 UNKNOWN 当无影响。

## 结果

本地验证通过：后端 38 项（新增 8 项）、前端 30 项单测、8 项公共页面浏览器检查、6 项第一阶段演示回归、类型/构建和文档导航检查。新增后端用例在修复前已重现无语音误入分析、空结果校验不足等失败。

证据在 `.local-data/evidence/no-speech/`。公网部署与两条记录恢复将在本次发布验证后补充，不以本地通过代替线上结果。
