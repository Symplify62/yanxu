真实后台入口仍为 `/account.html`。系统管理员登录后进入管理概览，只看到全局管理导航：所有录音、用户、角色、部门、声纹、App版本。后台不显示“我的录音”“个人设置”；非管理员账号仍可使用本人录音与个人改密入口。页面显示当前 API 的环境标识，不根据浏览器地址猜测环境。概览使用本环境数据库的录音、处理、失败、云同步、人员和声音任务数量；它不声称 Mac 转写 worker 实时在线。手机 390px 使用可展开导航，人员与声音档案改为摘要卡，关键身份、状态和操作无需横滚。

系统管理员的 `GET /api/admin/recordings` 包含本环境全部录音，访客免登录录音、账号录音、尚在上传、处理失败和已完成记录都计入；支持标题/录制人搜索、来源与状态筛选、分页。`GET /api/admin/recordings/{id}` 提供音频就绪状态、录制归属、参会名单、完整 AI 分析和可归属姓名的逐字稿；无音频时不显示播放/下载。接口只给内建系统管理员，普通用户的 `/api/managed/recordings` 仍按本人/参会范围，不因后台扩展而变成全局记录。概览的录音总数与全量列表使用同一范围。录音上传令牌和服务器文件路径不进入管理接口。

`/api/admin/app-versions` 仅内建 `admin` 角色可操作；自定义角色即使有用户或角色维护权限，也不能上传、发布或回退 APK。当前环境的包名、HTTPS 源站和独立 artifacts 目录来自服务端环境配置；前端无法指定目标环境。登录页与后台均显示环境。普通用户和匿名访问继续不能读管理版本清单。

| 操作 | 接口与规则 |
| --- | --- |
| 查看 | `GET /api/admin/app-versions`：当前清单、候选/历史版本、最近操作；`GET /api/admin/overview` 给出运行计数。 |
| 上传 | `PUT /api/admin/app-versions/candidate?notes=...`，请求体是原始 APK（`application/vnd.android.package-archive`），上限 100 MB。服务器运行 `aapt` 与 `apksigner` 检查包名、版本、最低 SDK、单签名和与当前版本一致的证书，再计算 SHA-256；候选存于不公开的 `artifacts/candidates/`。生产环境没有已发布基线时拒绝首次上传。 |
| 发布 | `POST /api/admin/app-versions/publish` 提交候选 SHA-256 和页面所见的当前 SHA-256。服务端重新核验文件、包名、证书、版本递增和并发基线；先将文件移至不可变 `releases/`，再原子切换 `android-update.json`。更新清单变化后设备下次检查才发现新版本。 |
| 回退 | `POST /api/admin/app-versions/rollback` 只接受历史上已发布、版本号低于当前版本的同签名 APK；同样校验并原子切换清单。已安装较新版本的设备不会自动降级，已公开的旧下载链接也不会因此失效。 |

上传、发布、回退记录操作者、时间与目标哈希；清单切换前先留尝试事件，成功后留完成事件。版本目录总量设 2 GiB 上限，达到后需由运维核对引用与保留策略再清理，后台不提供无审计的直接删除。服务器须安装可用的 `aapt`、`apksigner` 和 Java；缺少工具时拒绝上传/切换，不跳过校验。Nginx 仅在候选上传路径允许 100 MB，请求仍需登录令牌。
