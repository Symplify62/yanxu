# 言序 Android App

原生AudioRecord采音、麦克风前台服务、PCM/WAV本地保存、JobScheduler可恢复上传。界面沿用A风格；公共结果页在App中读取真实服务。打开App可直接普通录音，选人和声音档案按需登录；公共WebView仍匿名，登录后的实名逐字稿走原生受保护接口。DeepSeek密钥不进入App。

当前已发布 **0.3.1（versionCode 11）**，访客录音与按需登录的实施、验证和发布状态见[0.3.1实施记录](../docs/implementation/android-guest-recording.md)。保留头像选人、全选、本人声音录制及云端登记。上一版0.3.0已于2026-09-22上线对应后端并发布自动更新清单，历史安装与验证见[0.3.0发布验证](../docs/implementation/identity-voice-release.md)；0.3.1以本轮实施记录中的新鲜发布校验为准。完整后端及发布边界见[真实身份与声音实施](../docs/implementation/identity-voice-delivery.md)。0.2.0历史验证见[本机人员与声音接入](../docs/implementation/android-local-speakers.md)。

App默认连接 `https://yanxu.qjl666.xyz`，联网使用无需USB。曾手动填写其他服务地址的安装会保留原设置，需在“设置”中确认；旧本地已上传记录不批量重新发布。公网运行与实测证据见[部署记录](../docs/implementation/public-deployment.md)。

## 移动端视觉整理（本地 0.3.2，尚未发布）

本轮将原生界面统一到共享 `AppUi` 和完整任务页 `AppPage`，见[视觉规范、验证及安装包](../docs/implementation/android-visual-system.md)。顶部头像是账号入口：未登录进入登录页，登录后进入个人设置；个人设置可输入旧密码修改密码，成功后重新登录。基础录音仍免登录。

设置不再使用连接弹窗；服务地址位于设置→高级设置，导入音频移到录音页和本地录音页。手机首页展示一排人员，更多人员页可搜索、筛选、全选和逐人录声。公共结果的 Web 改动需要相应前端部署，不能仅凭安装新 APK 判断线上页面已经更新。

## 构建与使用

JDK17、Android SDK35；`local.properties`设置本机sdk.dir（不入库）。首次依赖下载需要网络，已安装后可离线构建：

```sh
./gradlew assembleDebug
```

调试构建输出：`app/build/outputs/apk/debug/app-debug.apk`；本轮交付使用上方带版本的安装包。debug允许HTTP连接本地开发服务，release不允许明文；当前是测试包，不是商店发布包。

USB调试时在Mac执行`adb -s <设备ID> reverse tcp:5189 tcp:5189`，App“设置”中的服务地址用`http://127.0.0.1:5189`。离开USB转发后这个地址不再指向Mac；局域网方式需另行配置Mac监听和地址。

首页始终提供“开始录音”和顶部头像入口。未登录可以直接普通录音，点击开始时才请求麦克风权限，录音期间有系统通知。暂停只暂停写入，计时为有效音频时间；结束后本地保留原件、自动上传，公共记录可看到处理结果。录音页和本地录音页的导入音频同样无需登录。

“选择参会者”“声音档案”在未登录时打开全屏账号登录页；登录并同步目录后继续刚才的操作。取消或登录失败不打开麦克风，登录成功本身也不开始录音。没有record权限的普通成员可以普通录音、维护本人声音，不能选择会议名单。

## 文件与恢复

本地文件位于App私有recordings目录，每条有稳定UUID、WAV或导入文件和原子更新的meta.json。录音按秒更新WAV头/刷盘。异常退出后再次启动会修复保留内容并标记“录音中断”，上传时保留interrupted标识，不宣称整场完整。

网络/服务临时失败由JobScheduler重试，分片状态从服务器恢复；永久4xx错误保留本地文件并显示受阻，不无限重试。重试按钮仅安排现有文件上传，不启动转写之外的新业务。

## 当前验证边界

已在独立API36模拟器验证开始/暂停/继续/结束、本地文件及自动上传；导入真实会议音频到后端完成Qwen和DeepSeek闭环。当前连接的安卓手机已安装测试包，但未由自动化开启其麦克风。物理手机拾音、OEM后台限制、锁屏/来电中断、长时长和后续平板仍需真机测试。

WAV单文件有容器容量边界，服务默认也有单文件上限；不把“没有业务时长倒计时”表述成无容量限制。App数据不可随意清空，尚未增加用户删除录音功能。

## 自动更新

新增版本支持自动检查、下载与空闲时自行安装，系统要求时提示授权或确认。启动与后台周期检查，录音/待上传期间延后；可在设置的“应用更新”关闭自动更新。旧0.1.5需先覆盖安装新版。安装器和服务器发布、签名要求、验收结果见[自动更新说明](../docs/implementation/android-updates.md)。

## 账号、声音与会议归属（0.3.1）

- 首页头像或设置→账号登录；选人/声音入口也可按需转入全屏登录页，成功后同步并续接原功能。token和账号资料以Android Keystore AES-GCM加密保存，不在日志、录音meta或WebView中注入。账号停用与权限由后端检查。
- 目录和本机声音按服务地址＋账号隔离。退出/切换服务保留文件但不显示另一账号目录、具名本地名单或受保护结果；待传录音持续绑定原账号和服务，不能以新账号接管。具名录音会话过期时等待原账号登录，恢复后继续上传同一录音。
- 登录后“同步人员与声纹”；每个人头像的声音入口可录制、试听本机声音、明确云端同意后上传、刷新生成状态、撤回。声音已保存在本机、云端生成中和云端可用是不同状态；上传不等于识别完成。云端登记要求3至120秒，本机旧样本范围保留兼容，超出范围提示重录，不静默裁剪。
- 云端已有姓名在录制页只读，纠错在有权限的管理后台完成，避免本机改名与服务器指向不同人员。服务器登记同时校验confirmedName，目录变化需刷新再确认。
- 登录后的“添加人员”直接调用受record权限保护的POST /api/people，创建无登录账号的参会者；仅填写姓名、备注，不能借此创建账号或授予角色。成功后同步云目录，允许选择和独立登记声音。旧本机人员仍需明确选择对应云人员或显式新建，不按姓名合并；未关联的已选人员会阻止具名会议开始，可取消该选择后录音。
- 0.2.0声音没有云保存授权。“账号与云端资料→迁移旧版本机声音”逐个选择旧样本、明确对应云人员，复制后再单独确认云端保存。原件保留，首次迁移后归属固定，其他账号不能读取迁移列表。
- 录音和导入开始时冻结模式与目标服务。未登录、无名单的过期会话或无record权限普通成员使用anonymous模式，元数据不带cloudIdentity和人员快照；后续登录不接管这条录音，切换服务也不改变原上传目的地。
- 有效record账号的新录音继续使用managed模式，冻结人员ID、owner账号、服务地址和rosterClientId；即使没有选人也保留账号归属。会议期间名单锁定，重试失败、退出或换账号均不降级匿名。旧0.2.0匿名文件继续兼容。
- 已选参会者后登录过期，界面隐藏缓存名单；重新开始时要求登录或显式“清空本场名单”，不会默默丢掉名单按普通录音开始。清空仅改变本场选择，保留声音和历史录音；用户须再次点击开始录音。
- 公共记录WebView不携带token。公共页上方“我的会议·具名逐字稿”通过受保护分页接口展示本人创建或参与且被授权的会议，普通已登录参会账号不必有录音权限。已上传受保护本地录音也可通过“查看结果”打开同一原生实名逐字稿；服务端仍负责匿名编号投影。说话人处理中/失败显示必要状态，失败保留文字。当前原生实名结果主要是文字展示，完整音频回听仍在公共结果页。

## 隔离验证

既有SpeakersInstrumentation保留checks/ui/panel。新增`cloudchecks`仅在独立模拟器临时目录和独立偏好中运行：Keystore读写、退出/服务/账号隔离、固定名单与owner、显式旧样本复制、重试编号、HTTP与重定向拒绝。

`cloudapi`必须显式提供`apiServer=http://10.0.2.2:<本地端口>`、`apiUser`和`apiPassword`，拒绝公网地址。使用可丢弃后端库验证登录、record-only组织者新增无账号参会者且管理接口拒绝、目录、缺少云同意被拒、私有WAV上传/complete、managed名单及分片、匿名拒绝、撤回和登出失效。合成音频只验证协议，不证明真实声纹准确率。设备运行截图和真实模型证据由总体验收记录统一收集；生产服务/自动更新/真实同事授权另按部署门禁执行。

0.3.1新增`guestchecks`，在隔离目录/偏好和回环HTTP中验证匿名录音模式、固定上传服务、后来登录不接管、具名录音不降级、失效/权限边界、启动竞态、实际分片上传及原音字节一致。当前测试与待验收项统一记录在[0.3.1实施记录](../docs/implementation/android-guest-recording.md)，不使用线上账号或真实同事声音。
