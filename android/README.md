# 言序 Android App

原生AudioRecord采音、麦克风前台服务、PCM/WAV本地保存、JobScheduler可恢复上传。界面沿用A风格；公共结果页在App中读取真实服务。无需账号，DeepSeek密钥不进入App。

当前测试版 **0.1.5** 默认连接 `https://yanxu.qjl666.xyz`，联网使用无需USB。曾手动填写其他服务地址的安装会保留原设置，需在“设置”中确认；旧本地已上传记录不批量重新发布。公网运行与实测证据见[部署记录](../docs/implementation/public-deployment.md)。

## 构建与使用

JDK17、Android SDK35；`local.properties`设置本机sdk.dir（不入库）。首次依赖下载需要网络，已安装后可离线构建：

```sh
./gradlew assembleDebug
```

调试包：`app/build/outputs/apk/debug/app-debug.apk`。已复制到根目录`.local-data/artifacts/yanxu-debug.apk`供本地服务下载。debug允许HTTP连接本地开发服务，release不允许明文；当前是测试包，不是商店发布包。

USB调试时在Mac执行`adb -s <设备ID> reverse tcp:5189 tcp:5189`，App“设置”中的服务地址用`http://127.0.0.1:5189`。离开USB转发后这个地址不再指向Mac；局域网方式需另行配置Mac监听和地址。

点击开始录音时请求麦克风权限，录音期间有系统通知。暂停只暂停写入，计时为有效音频时间；结束后本地保留原件、自动上传，公共记录可看到处理结果。设置中的导入音频可用于测试已有素材。

## 文件与恢复

本地文件位于App私有recordings目录，每条有稳定UUID、WAV或导入文件和原子更新的meta.json。录音按秒更新WAV头/刷盘。异常退出后再次启动会修复保留内容并标记“录音中断”，上传时保留interrupted标识，不宣称整场完整。

网络/服务临时失败由JobScheduler重试，分片状态从服务器恢复；永久4xx错误保留本地文件并显示受阻，不无限重试。重试按钮仅安排现有文件上传，不启动转写之外的新业务。

## 当前验证边界

已在独立API36模拟器验证开始/暂停/继续/结束、本地文件及自动上传；导入真实会议音频到后端完成Qwen和DeepSeek闭环。当前连接的安卓手机已安装测试包，但未由自动化开启其麦克风。物理手机拾音、OEM后台限制、锁屏/来电中断、长时长和后续平板仍需真机测试。

WAV单文件有容器容量边界，服务默认也有单文件上限；不把“没有业务时长倒计时”表述成无容量限制。App数据不可随意清空，尚未增加用户删除录音功能。

## 自动更新

新增版本支持自动检查、下载与空闲时自行安装，系统要求时提示授权或确认。启动与后台周期检查，录音/待上传期间延后；可在设置的“应用更新”关闭自动更新。旧0.1.5需先覆盖安装新版。安装器和服务器发布、签名要求、验收结果见[自动更新说明](../docs/implementation/android-updates.md)。
