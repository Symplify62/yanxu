# 正式组件原型迁移验证约定

范围：用户认可将现有原型迁为正式组件工程。业务按v1.3 U-11，平板保存页仅下一场扫码，没有手机跳转按钮。真实后端、企业微信、AI、音频和群出口不在本轮。

当前外层是文档目录，无Git仓库或现有应用工程；frontend为新建独立工程，旧HTML/PRD/ZIP保持原样。不把其他项目代码或配置复制进来。

技术：Vue 3 + TypeScript + Vite，Element Plus后台/平板网页预览，Vant员工手机，Vue Router页面路由，MSW网络模拟。Mock与页面分离；页面只调用带类型的HTTP服务。原生Android不在本次Web迁移中。

行为范围：员工/管理员模拟登录隔离、每场扫码及过期/停用/首次开户、本地保存/退出后独立队列、自动处理/通知、本人及只读共享资料、手机可选更正和事项、不重复发送、部门群规则/异常/账号/组织/角色/组、组件状态展示页。未知资料/无权限/服务错误有可见反馈。

编辑前验证：安装版本锁定；类型检查与构建；模拟服务测试（身份、版本冲突、只读/撤权、发布快照、失败/UNKNOWN）和真实浏览器端到端（正常全流程、退出/下一场、共享/更正/异常）；组件展示与桌面/手机/平板截图。测试不声称生产安全。

图谱：新工程先无既有代码可分析；建立源码后在独立frontend仓库建立GitNexus索引，后续跨模块调整按图谱影响检查，动态Vue模板/MSW匹配以源码及接口测试补证。

交付：可启动工程、锁文件、README/技术选择及模拟接口清单、验证证据、可见本地预览。无提交/推送/公网发布授权，保持本地。

状态：本轮正式组件原型交付完成，正式产品未验收。

## 实际验证

- npm run typecheck：通过；组件全局类型生成后再次检查并修复表格行类型适配。
- npm run build：通过；正式组件按需导入，路由懒加载。
- npm test：30项规则与模拟HTTP契约检查通过，覆盖扫码/归属/退出、权限与共享、版本冲突/快照、不确定发送、停用、配置并发等。
- npm run test:e2e：6条Chrome浏览器流程通过（约40秒），报告evidence/playwright-results.json。正常路径从真实组件点击并经过MSW请求，不直接改页面全局状态。
- 冷开发导航检查：evidence/dev-navigation-result.json，初始/结束页面启动次数均1，脚本错误0；已关闭首次路由预构建刷新导致mock重置的问题。
- Ego浏览器taskSpace 38：9个场景截图，1600/1280/1024/960/390宽度均无整页横向溢出；组件过渡结束后截取。已实际查看平板、手机详情/更正、管理群规则和组件展示图。
- 依赖npm audit：0项报告漏洞；不据此声明整个产品安全。

## 修复与证据边界

最初TS 7与vue-tsc的tsc导出不兼容，固定TS5.9.3后构建通过。组件声明生成后发现Element Plus表格行泛型不够具体，改为按ID回查已类型化数据，避免不可靠的行对象复制。MSW初始化首次在外层目录执行失败，已在frontend内正确生成worker，未向外层写入应用配置。

开发模式深层样式依赖触发预构建刷新，初步glob未覆盖无扩展名的导入；最终采用明确根依赖与noDiscovery，独立冷导航复测无刷新。界面截图初次过渡动画未结束，捕获脚本改为等待进入过渡结束。员工手机和后台的状态颜色统一到设计变量。

GitNexus已建立并刷新。revoke变更影响3个上游节点、LOW；网络及表格回调在Vue模板中，图谱未解析调用者，已核对对应事件绑定并用真实浏览器补证。clearSession查询显示7个上游节点/高影响，本轮没有修改其清理规则，只将路由回调改为静态导入，相关登录/切换/过期路径按实际测试验证。图谱流程有预算截断及跨语言字段覆盖缺口，不据无边/缺流程推断无影响。

本轮测试都针对组件前端与mock服务；不代表真实企业微信/后端、Android、录音、AI、群发送和生产权限通过。v1.3的128个正式产品用例不回填为通过。
