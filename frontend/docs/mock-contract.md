# 当前模拟接口与替换边界

所有路径前缀/api/v1。请求由MSW浏览器worker拦截，不访问真实服务。员工和管理员使用不同演示会话；这些头/身份机制不用于生产。

| 接口组 | 当前行为 | 真实接入时必须补齐 |
| --- | --- | --- |
| /auth/demo-login、/session | 模拟企业身份、首次开户、退出、过期 | 实际企业微信认证、会话安全、组织同步、恢复流程 |
| /device/challenge、/scan、/start、/actions | 本场人员/归属固定、录音状态与结束 | 设备认证、一次性挑战服务、真实采音/封存/重启恢复 |
| /device | 最小队列元数据，不含历史正文 | 上报时间、离线有效性和真实收据 |
| /meetings、/:id、/transcript | 本人/授权查询，无权与不存在统一拒绝 | 持久库、分页/搜索权限、真实资产媒体访问 |
| /meetings/:id/revision | 乐观版本检查、更正原因、保留旧快照 | 正式版本/证据与并发事务 |
| /meetings/:id/grants | 公司内只读共享、撤销本人来源 | 全量委派、组历史边界、撤权窗口与审计 |
| /admin | 只提供任务元数据、组织/角色等 | 真实管理权限、日志和可观测数据 |
| /admin/routes、/groups、/users | 配置版本、成员、停用与会话撤销 | 正式事务、受众确认、权限影响计算 |
| /admin/recover、/pause | 当前状态复查，UNKNOWN不重发 | 真渠道查询/人工依据、任务恢复及持久去重 |
| /demo/* | 演示故障/重置，仅在mock注册 | 生产不得带此控制入口 |

MockDatabase是测试夹具和模拟服务状态机，不是计划上线的后端。共享界面组件和HTTP调用可复用；认证、持久性、队列、费用、发群和服务端安全须重新用真实层级验收。

## 时间单位与正式契约

当前Web演示模型的duration、elapsed以秒计，时间点为ISO字符串；这不是已冻结的生产DTO。正式DES-02以duration_ms/start_ms等毫秒语义为依据，接入时应在services适配层统一字段和单位并补契约测试，不能将模拟字段原样当生产协议。
