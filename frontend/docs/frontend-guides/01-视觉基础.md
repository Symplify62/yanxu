# 01 视觉基础

触发：颜色、字体、间距、圆角、边框、图标或动画修改。布局请转[02](02-布局与多端.md)，行为请转[04](04-交互状态与文案.md)。

## A的视觉方向与来源

暖白、低饱和绿色、适度圆角，状态突出但装饰克制。已选[Element Plus A方案](../design-lab/selection.md)。以实际A源样式为执行来源，历史DES-05颜色建议不再作为当前值。

| 语义 | 当前执行位置/变量 | 使用边界 |
| --- | --- | --- |
| 主要文字、辅助文字 | [full.css](../../src/design-lab/full/full.css)的`--full-ink`、`--full-muted` | 层次由语义决定，不把重要错误弱化为辅助色 |
| 页面、面板、弱背景、侧栏 | 同文件`--full-paper/panel/soft/rail` | 用于区分工作区，不在每个字段外堆卡片 |
| 主色、边框、圆角 | 同文件`--full-accent/line/radius` | 主色用于主操作/选中；业务成功另有文字状态 |
| 平板主题 | [option.css](../../src/design-lab/option.css)中`.tablet-app`及`data-design=element` | 当前局部变量与full变量分开；复用现有值，跨端调整需同时检查 |
| Element主题 | 同option.css的`--el-*`变量 | 经主题变量覆盖库样式，避免逐页覆写不稳定内部结构 |
| 图标 | 当前使用`@lucide/vue`，见[package.json](../../package.json) | 同界面保持线宽、尺寸、对齐；纯图标操作给可读名称 |

新共用样式优先引用已有语义变量。新增变量必须说明语义及复用位置；同义变量先合并设计意图。此任务未重构现有两组变量，不能称已具备统一token生成系统。

## 字体、间距与层级

中文使用系统字体回退；当前字体栈见option.css。正文可读性优先，长中文允许换行；数字时长使用等宽数字，避免跳动。当前全局正文14px、会议正文15px等具体规则以full.css为准。

使用一致的4/8基础间距节奏，特殊布局尺寸有场景依据。标题、正文、说明、状态四层通过字号/字重/留白区分；不要靠反复加粗或颜色堆层次。

当前原型部分辅助文字为10–11px；这是现状，不是新增页面必须复刻的下限。新增说明优先保证可读，现有小字、大字体与对比度检查列入[06验收](06-验收与维护.md)。

## 状态与动效

成功/警示/失败/信息必须同时有文字或图标。录音进行、暂停、保存失败要可辨认；静态截图和减少动态效果设置下也能理解。

当前有`prefers-reduced-motion`处理，保留此分支。动画仅解释状态或空间变化，避免长时间阻挡操作；具体持续时长先复用库和现有样式。

## 完成检查

改共用变量后至少检查平板扫码/录音、手机正文、后台表格、弹窗。检查长名称/中文换行、禁用和焦点样式。截图证明外观，触控和对比度需分别验证；不以主色统一代替整套设计验收。
