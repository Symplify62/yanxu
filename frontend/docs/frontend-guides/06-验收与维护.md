# 06 验收与维护

> 第一阶段范围见[免登录录音与公共结果](../../../docs/phases/phase-01.md)。本期不实施扫码/员工身份、个人与共享范围、组织角色或发群。下文旧完整原型的页面、API和测试是复用参考，不能替代本期新流程与真实能力验收。

触发：测试、截图、可访问性检查、交付或规范变更。命令以[package.json](../../package.json)为准；本文件指定如何选择验证范围。

## 规格、用例、证据的关系

页面外观/位置/状态/交互是[DES-10页面规格](../../../会议室录音系统_PRD_v1.3/docs/design/DES-10-页面级设计与交互规格.md)及本目录的规定；测试用例据此写触发、输入、期望结果。映射参考[UI-01](../../../会议室录音系统_PRD_v1.3/docs/acceptance/UI-01-页面与组件测试对应.md)、[TEST-01](../../../会议室录音系统_PRD_v1.3/docs/acceptance/TEST-01-验收用例库.md)，不以高层PRD代替按钮具体结果。

| 改动范围 | 最小有意义验证 |
| --- | --- |
| 单处文案/样式 | 格式/构建按需要＋该页浏览器截图；不为低风险替换写镜像单测 |
| 共享视觉变量/布局 | 录音、手机详情、后台表格、弹窗的受影响代表页＋宽度/长文检查 |
| 组件行为/表单 | 加载、取消、错误保留、重复提交、键盘/焦点；关联实际调用页 |
| 身份/共享/更正/自动处理 | 对象范围、撤权、跨角色流程、版本冲突、保存后退出、不重复外发 |
| API/mock状态 | 模型/HTTP测试＋实际页面调用路径；不能只mock掉待验证错误 |
| 文档/AGENTS/仓库配置 | 根目录文档链接检查、导航触发条件、暂存清单；无UI变化时不新增截图要求 |

使用仓库Playwright做长期回归，交互探索按全局浏览器规则。复用归属明确的本地服务，不把旧构建当新结果。测试失败保留原因；修正实现/测试定位/环境后重跑原路径。

## 可访问性与设备检查

键盘全路径、可读标签、焦点恢复、对话框焦点约束、大字体、中文长名称、颜色对比度、减少动态效果、触控尺寸分别验证。仅截图正常不证明上述检查完成。

已知待验/待实现：原型小号辅助字、全部页面的对比度量测与键盘覆盖、草稿关闭保护、字段首错误聚焦、技术失败/无权文案完整区分、原生平板dp与持续录音能力。已选A是视觉方向确认，不能用它豁免上述标准；本次文档整理不实施这些功能。

## 证据与维护

证据放对应任务目录，记录日期、入口、实际命令、结果和边界；历史结果不回写成当前成功。前端既有记录在[design-lab验证](../design-lab/verification.md)，本轮仓库文档验证在[根仓库记录](../../../docs/repository/bootstrap-verification.md)。

变更共用变量同步01；布局同步02；组件契约同步03；反馈/术语同步04；架构位置同步05；验证要求同步本页。仅对发生变化的来源更新，规范正文不按每次运行追加流水账。

真实服务或发布任务另读[ACC-02工程验证](../../../会议室录音系统_PRD_v1.3/docs/acceptance/ACC-02-工程测试与发布验证.md)和[发布检查](../../../会议室录音系统_PRD_v1.3/docs/delivery/DEL-02-部署运维与上线检查.md)。默认没有真实身份、录音、AI、外发或生产验收证据。
