## 三层职责

- 本目录：跨页面复用的前端规则；每份规范同时说明实现位置与未完成边界。
- [DES-10页面规格](../../../会议室录音系统_PRD_v1.3/docs/design/DES-10-页面级设计与交互规格.md)：页面/组件位置、动作、输入和结果。
- [业务规则地图](../../../docs/README.md)：产品范围、状态、权限、生命周期等权威来源。

上述层级分工，不互相替代。当前源码与规范不一致时记录差异；保留既有批准业务规则，不能把现状自动提升为标准。
