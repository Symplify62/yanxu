# 02 布局与多端

> 第一阶段范围见[免登录录音与公共结果](../../../docs/phases/phase-01.md)。本期不实施扫码/员工身份、个人与共享范围、组织角色或发群。下文旧完整原型的页面、API和测试是复用参考，不能替代本期新流程与真实能力验收。

触发：页面结构、导航、信息密度、响应宽度、表格或弹窗滚动。具体某页的位置/动作先定位[DES-10](../../../会议室录音系统_PRD_v1.3/docs/design/DES-10-页面级设计与交互规格.md)页名；本文管理跨页面规则。

## 三端主任务

| 端 | 稳定结构 | 主任务与操作 |
| --- | --- | --- |
| 平板 | 设备顶栏＋本场主区＋简短自动流程说明 | 扫码、开始/暂停/结束、保存结果；保存后只提供下一场入口 |
| 员工手机 | 顶部返回/身份＋单栏资料＋资料标签 | 找到本人/共享会议，阅读纪要、逐字稿、事项、录音与版本 |
| 管理后台 | 固定导航＋工作区顶栏＋单模块工作区 | 概览看状态，用户/规则用表格，组织用部门导航＋成员表 |

共用文字与状态语义，三端不强求相同密度或布局。管理界面不展示会议正文来填充空白；手机的资料阅读与平板本场录音保持不同入口。

## 当前实现定位

- [Lab.vue](../../src/design-lab/Lab.vue)：外部评审导航、场景控制、视口选择与iframe；这些控件不属于产品内部页面。
- [TabletOption.vue](../../src/design-lab/TabletOption.vue)：已选A的平板流程；样式见a-theme.css。
- [EmployeeApp.vue](../../src/design-lab/full/EmployeeApp.vue)：手机列表/详情与操作；样式见a-layout.css。
- [AdminApp.vue](../../src/design-lab/full/AdminApp.vue)：导航与主工作区；状态/表格数据在useAdminModel中。

布局容器要直接承载其grid/flex子区域；页面和表格容器设置可收缩宽度。一个页面以一个主要任务为中心，避免多个管理模块堆在同一个长页。

## 多端与滚动

按内容而非设备名决定断点。当前CSS断点见[a-layout.css](../../src/styles/a-layout.css)与[a-theme.css](../../src/styles/a-theme.css)；已做1280/768/390等样板检查，实际目标Android设备仍需验证。

- 手机单栏，主操作可见，不依赖悬停；标签过多时提供可理解的滚动，文字不无故截成单字。
- 后台窄屏允许导航和表格各自在容器内横向滚动，文档整体不得被撑宽。操作列必须能通过表格滚动到达。
- 长表单保持标题和操作区可见，正文独立滚动；底部操作不能遮住最后字段。当前Dialog适配已有此实现。
- 加载、空、错误与正常内容共享稳定工作区，避免上下文位置大幅跳动。

## 第一阶段 App 嵌入布局

- 原生壳负责品牌、设置和“快速录音/公共记录/本地录音”导航；WebView负责筛选、列表和详情。当前导航已命名的列表，在WebView中不再显示同名可见大标题或保留标题占位；用区域名称维持可访问性。独立网页保留页面标题。
- 公共记录导航与WebView直接衔接，原生壳下方不叠加24dp空白；嵌入网页主区顶部内边距为0，左右8 CSS px（外层原生壳已有20dp边距）。详情仍保留记录自己的标题。
- 列表工具栏是内容滚动区内的吸顶层：顶边为WebView视口顶边，不按整块物理屏幕定位；滚动记录时筛选与搜索保持可用。白底/背景、层级和首末条可见性一并验收。
- ≤650 CSS px使用两行：状态筛选＋搜索；记录数并入搜索行。标准字号下目标约100 CSS px高，不再加独立计数行；状态按钮触控高度≥44 CSS px，输入框≥40 CSS px。放大字号时允许工具栏增高，保留可读性与触控区域。
- 实现入口：[ResultsPage.vue](../../src/records/ResultsPage.vue)、[PublicApp.vue](../../src/live/PublicApp.vue)、[phase-one.css](../../src/styles/records.css)；Android原生导航间距见[MainActivity](../../../android/app/src/main/java/cn/jiajian/yanxu/MainActivity.java)。执行步骤与证据见[本轮布局修正](../../../docs/implementation/app-list-layout.md)。

## 布局验收

至少检查桌面宽度、目标平板横/竖屏、390手机宽度；验证最长实际文案和大字体。当前平板是Web预览，CSS像素不等于真机dp，触控标准与平台缩放单独验收。页面更改同步该页规格或记录既有规格实现缺口。
