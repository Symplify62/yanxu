## 当前组件边界

A使用Element Plus；版本以[package.json](../../package.json)为准。实际业务界面注入[Kit接口](../../src/design-lab/full/context.ts)，A适配位于[kits/element.ts](../../src/design-lab/kits/element.ts)。B/C组件与专用依赖已移除，后续组件需求沿用A方案。

| 共用控件 | 当前适配 | 变更时检查 |
| --- | --- | --- |
| Button | [ElementButton](../../src/design-lab/kits/ElementButton.vue) | 主/次、禁用、加载、防重复提交、可读名称 |
| Input | [ElementInput](../../src/design-lab/kits/ElementInput.vue) | 文本/多行、标签、错误定位、只读/禁用需求 |
| Select | [ElementSelect](../../src/design-lab/kits/ElementSelect.vue) | 候选来源、权限过滤、加载/无候选/失败区别 |
| Checkbox | [ElementCheckbox](../../src/design-lab/kits/ElementCheckbox.vue) | 点击可见label、键盘和选中语义；不要只测隐藏input |
| Table | [ElementTable](../../src/design-lab/kits/ElementTable.vue) | 表头、空/错、长内容、容器滚动、操作列可达 |
| Dialog | [ElementDialog](../../src/design-lab/kits/ElementDialog.vue) | 标题、正文滚动、取消/确认、焦点、长表单/手机高度 |

通过适配封装跨页面约定；业务API、对象权限、字段规则留在业务层。已有契约不足时扩展共用接口并检查调用处，不让模板绕过权限或直接访问MockDatabase。

## 业务模式

第一阶段公共列表工具栏由“状态筛选＋搜索＋记录数”组成一个稳定区域：记录数为搜索框尾部辅助信息；加载、无匹配和清除筛选期间保留控件位置。移动端两行吸顶，尺寸、标题职责和滚动边界以[02的App嵌入布局](02-布局与多端.md)为准。组件库只提供控件，不能代替这些组合规则。

| 模式 | 当前实现或规范来源 | 必须保留的语义 |
| --- | --- | --- |
| 本场录音与结果 | TabletOption＋[useTabletDemo](../../src/design-lab/useTabletDemo.ts) | 保存成功前不能假退出；保存、上传、处理、分发分别表达 |
| 会议资料 | EmployeeApp | 各资料就绪后可读；原文依据可追溯；未知说话人不补实名 |
| 更正与版本 | EmployeeApp内更正弹窗 | expectedVersion、原因、原稿与群快照保留；保存不重发 |
| 只读共享 | EmployeeApp内授权弹窗 | 内容范围独立、可撤销；不授编辑/下载/管理权 |
| 角色/访问组/分发配置 | AdminApp＋useAdminModel | 角色不自动扩大正文范围；变更有版本/确认/错误反馈 |
| 异常接管 | 同上，STATE/ACL | 恢复失败阶段；未知发送结果核查，不能强制假成功 |

规格中的音频证据播放器、自定义RoleScopeEditor、完整分片诊断等尚不是已完成生产组件；先查[DES-10](../../../会议室录音系统_PRD_v1.3/docs/design/DES-10-页面级设计与交互规格.md)和源码，不把名称存在误判成能力存在。

新增组件时交付输入/事件/状态/可访问性约定与至少一个实际调用场景；复用与新增的判断记录在任务说明。组件样例在ComponentGallery，页面行为仍需E2E验证。

## Android 原生组件

原生 App 不直接复用 Element Plus。修改 Android 界面时使用 [AppUi](../../../android/app/src/main/java/cn/jiajian/yanxu/AppUi.java) 的文字、按钮、输入框、头像与设置项，使用 [AppPage](../../../android/app/src/main/java/cn/jiajian/yanxu/AppPage.java) 的完整页面容器；数值以代码为准。

- 录音首页右上角只显示一个头像。未登录显示人形，点击进入登录页；已登录显示姓名首字，点击进入个人设置。应用设置从登录页或个人设置进入，不在首页另放文字入口。
- 导航项使用标题、必要状态与箭头，不伪装为提交按钮；主动作使用实心绿色，次动作浅底，轻操作无底，退出/撤回使用危险色。禁用状态同时弱化背景和文字。
- 设置、个人设置、选人、声音档案和录声使用完整页面；长内容滚动，主要操作保留可达。小型确认才用对话框。
- 人员元素只显示头像和姓名；选中用头像上的勾标记。录声入口用角上的图标，给出可读名称，点击不改变人员选择。部门与声音状态可用于筛选、辅助技术读出或详情，不能堆在人员元素里。全选的作用域仍是当前可见/筛选结果，不能清除范围外选择。
- 录音页把“全选／取消全选”与“更多”放在参会者标题行；选人页把同一操作放在筛选项旁。按钮不重复展示人数和范围，辅助读出须明确当前作用域及人数。
- 登录、服务地址、修改密码使用同一输入框规范；错误不关闭表单，成功保存才改变状态。

页面布局和本轮证据见 [App 视觉系统整理](../../../docs/implementation/android-visual-system.md)。功能回归通过不替代整页、长姓名和大字体截图检查。
