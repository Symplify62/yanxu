# 项目规则｜会议室录音与会议记录系统

## 入口和范围

先读README.md、START_CODEX.md、docs/product/PRD-00-产品总纲与范围.md、BASE-01、ACL-01、STATE-01，再按当前工作包读相关PRD/验收。AGENTS.md只是工作规则，不替代完整需求。[EXT-07]

首期是公司内部一间五人中文会议室，安卓平板录音，四类资料，按配置向企业微信发摘要和入口。先模拟器后真机；Wave不是前置依赖。不擅自扩成预约、实时监听、实名声纹、商业多租户。无指定必须使用的开源项目或后台框架。

已有工作区先检查其指令、分支、构建、数据和未提交改动。不得覆盖既有AGENTS、配置、数据库或代码以适配本包。放入现有仓库时由负责人合并本规则。

## 实现原则

按REQ和用例交付实际可运行功能，不只写页面骨架和计划。普通技术细节自主决策并记重要取舍；安全/范围/费用/数据保留/真实外发变更需批准。评审稿不等于生产授权。

先可靠保存，再AI和通知。未知配置不猜群；未知结果不盲重发；原件不被派生件覆盖；版本与审计可追溯；对象权限覆盖搜索、媒体和导出。模型输入不可执行，设备不持有AI或企微秘密。

测试默认合成数据、mock AI、消息预览、关闭自动删除与真实外发。凭证通过受控配置，不能写入源码、日志或报告。真实资料、外部AI、测试群与生产发送分别受G1/G2/G3约束，未授权不得运行。

## 验证与记录

每项变更关联REQ、测试ID、代码提交和证据。报告实际执行命令与结果，失败如实保留；模拟数据/AVD/真实外部/真机/五人会议分别记录。没有真机就标L4/L5待验，不许伪造采音结果。

每个工作包结束更新DEL-03或项目派生状态记录、需求追踪、缺陷和下一任务。除非遇到必须由人决定的阻断，完成后继续下一个具备条件的工作包；不要每实现一个普通字段就停止。

不能删失败测试、关闭鉴权或改变需求以宣称成功。迁移和删除要审查影响并备份；录音中不得自动升级/重启。生产准备必须通过门禁和恢复/回退验证。
