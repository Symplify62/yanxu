# 嘉谏言序｜产品需求与实施设计文档包

**v1.2-draft · 2026-09-20 · 文档评审稿**

一套覆盖“要做什么、怎样实现、如何验证、怎样运行”的本地资料。首期保持单公司、一间通常五人的中文会议室、安卓平板录音、四类会议资料和按配置企业微信分发。

当前已交付文档与原型参考。具体技术栈、正式身份源、AI服务、真实群及生产参数未因本包自动确定；没有正式服务端、数据库或安卓安装包。

## 本版包含什么

产品总纲及7个业务模块、4份共用规则、DES-00至09实施设计、决策/六阶段交付/运维资料、业务与工程验收、机器索引和证据。业务需求保持96条，产品用例保持122个，均未实现/未执行；本轮没有为文档数量额外扩张业务功能。

附带[原型v0.2](原型/会议录音系统_可点击原型_v0.2.html)供回看；它仍基于v1.1业务原型，并未更新为新设计系统或真实权限实现。新增规范需在获实施授权后做组件库与代表页面验证。

## 文档状态与后续使用

Markdown为维护源。本次未生成新版Word/PDF；原v1.0阅读稿仅是历史版本。接口路径、实体字段和设计变量标为建议草案；正式API/OpenAPI、SQL和部署命令需要在相应技术决定后交付。

业务规则冲突按BASE/ACL/STATE处理，技术决定按DEC-01登记。若要交给开发任务，使用[交接入口](START_CODEX.md)并明确授权阶段；直接收到文档不会自动授权生产或外发。原AGENTS保持不变，项目边界按当前用户指令执行。

## 文档验证

文档结构检查：`python3 tools/validate_prd.py`；实施资料关联检查见tools/validate_design_docs.py。检查不执行产品功能。结果见DOCUMENT_QA.json、DESIGN_QA.json及[evidence中的本轮记录](evidence/文档交付验证_v1.2.md)。
